## 本教程的环境

- **云服务商**：独角鲸云（NAT 实例）
- **操作系统**：Debian 13.6（已启用 BBR 加速）
- **管理面板**：3x-ui v2.9.4
- **客户端示例**：v2rayN

建议按 Step 1 → Step 3 的顺序阅读操作。
